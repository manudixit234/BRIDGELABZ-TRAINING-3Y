# JavaScript Practice — Assignments 1–6

Each question is saved in its own JavaScript file. Browser-based exercises include their matching HTML page. Examples use core JavaScript and ES6+; no frameworks are required.

## Run
- Console exercises: run with Node.js, for example `node assignment-1/q1-login-greeting.js`.
- Browser exercises: open the matching HTML file in a browser.
- Assignment 6 Q6 needs an internet connection for the Fake Store API.

## Contents
- Assignment 1: variables, operators, conditions, loops and basic problem solving
- Assignment 2: scope, strings, arrays, functions and objects
- Assignment 3: strict mode, hoisting, validation, errors and debugging
- Assignment 4: classes, objects, forms, regular expressions and cart logic
- Assignment 5: callbacks, prototypes, inheritance, closures and custom array methods
- Assignment 6: Promises, async/await, event loop, fetch and retry logic
