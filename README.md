# Bootstrap Assignment 10
Ten responsive Bootstrap 5 exercises. Each question has its own HTML and CSS file and loads Bootstrap 5.3.3 from the official jsDelivr CDN.
## Run
Open any `assignment-10/qN-*.html` file in a browser with an internet connection. Bootstrap's JavaScript bundle is included only on pages that use interactive Bootstrap components.
## Topics
Landing page, portfolio, responsive product grid, restaurant menu, themed blog, alerts dashboard, task badges, pricing cards, pagination and travel carousel/progress bar.
